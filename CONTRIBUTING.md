# Contributing to Simple Interest Calculator

Thank you for your interest in contributing! All contributions, bug reports, bug fixes, documentation improvements, enhancements, and ideas are welcome.

## How You Can Contribute

- **Bug reports:** Open an issue describing the problem, the steps to reproduce it, and the expected vs. actual result.
- **Bug fixes:** Fork the repo, fix the bug, and open a pull request.
- **Documentation improvements:** Fix typos, clarify the README, or add examples.
- **Enhancements:** Suggest or add new features, such as compound interest or input validation improvements.
- **Ideas:** Open an issue to discuss suggestions before you start work.

## Getting Started

1. Fork this repository.
2. Clone your fork:
   `git clone https://github.com/<your-username>/simple-interest-calculator.git`
3. Create a new branch:
   `git checkout -b my-feature`
4. Make your changes and commit them:
   `git commit -m "Describe your change"`
5. Push to your fork:
   `git push origin my-feature`
6. Open a pull request against the `main` branch.

## Guidelines

- Keep changes focused and easy to review.
- Test your changes before submitting.
- Be respectful and follow our [Code of Conduct](CODE_OF_CONDUCT.md).
